## Cross-cutting evidence

- `GET /v1/capabilities` reads actual worker-lock, model and runner availability. The workbench handles offline/no-worker/no-runner/no-LLM states explicitly.
- `GET /v1/analyses/{id}/timeline` returns persisted timestamps; SSE supports Last-Event-ID and reconnect. A Playwright transport-abort test verifies recovery without replacing results with mocks.
- Exact UTF-8 AST spans are converted to Monaco's UTF-16 columns. Finding selection, heat-gutter, diagnostic hover, graph node selection and source inspection share source locations. Editing source or authored test contracts invalidates stale evidence immediately.
- Playwright covers 390px, 1440px and 1920px, theme persistence, fullscreen/Escape, editing, graph/diff navigation, immutable oracle revisions, caller regressions, abstention, replay, retrieval, twin, Shield and export.
- Trained model/data files and the container harness are preserved; the host adapter only gained canonical image-name compatibility. Current data: 111 retained pairs; 125/4/10/12 train/validation/calibration/test rows. **No measured ML localization uplift** and no external QuixBugs/family-holdout assessment are claimed. See the unchanged Phase 1 model card and actual metrics.

## Boundaries

Docker-only execution is development-grade and local-only. No public multi-tenant hardening or deployment is claimed. Optional configured LLM requests include source/context/test data; no external LLM service was exercised during these checks. Performance retains real median/p95 samples, but remains `PERFORMANCE_INCONCLUSIVE` under the current seven-call/separate-container protocol. New experiments do not certify universal correctness or broaden exact oracle scopes.
