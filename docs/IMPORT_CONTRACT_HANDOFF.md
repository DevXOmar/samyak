# Local Contract Studio and GitHub import changes

Contract Studio is failure-first, with returned/exploratory cases collapsed, per-case provenance/oracle/domain details and exact confirmation/rejection/replay actions. Candidate outputs are unverified proposals until explicitly confirmed. Witness search is attached to a selected failed case. Exception reductions must preserve JSON argument types/structure, exception class and exact submitted-source fault frames. Trusted logical mismatches retain their original oracle-backed input: reduction is inconclusive without an independently valid oracle for a changed tuple. No global minimum is claimed. The sorting Shield is behind collapsed Advanced property checks and requires an explicit supported contract.

Workbench's GitHub dialog uses `/v1/github/inspect` and `/v1/github/file`. Only canonical public `https://github.com/OWNER/REPO` URLs are accepted; API requests use the fixed GitHub API host, no credentials/proxy environment, no redirects, bounded timeouts/responses and no code execution. Default branch resolves to an immutable commit. Regular Python blobs are filtered and ranked deterministically, with up to eight bounded content probes so self-contained parsed functions/classes outrank inspected dependency-heavy entrypoints. A truncated/oversized tree falls back to at most eight directory reads. Results explicitly state partial-tree limits. GitHub rate/access restrictions return actionable 429 responses.

Selected files are pinned to their inspected SHA/path/blob identity, parsed as strict UTF-8 Python and capped at 60 KB as well as the existing 60,000-character limit. A small process-local cache holds at most 16 inspected revisions for ten minutes; stale selections require reinspection. Import clears fixture tests, stdin, job/report evidence and contract state, retains actual path/commit provenance and never starts Run/Analyze automatically. One file is the analysis unit; local/third-party imports carry dependency caveats and remain subject to the unchanged runner allowlist. No repository cloning, package installation or new services were added.

Generated OpenAPI types cover import responses. Deterministic backend tests mock only GitHub transport and exercise URL/path/SHA validation, symlink exclusions, bounded trees, ranking, UTF-8/syntax/source caps, rate limits, fixed-host fetching and refused redirects. Browser tests mock GitHub transport for import-state reset but submit real analysis jobs. `SAMYAK_GITHUB_SMOKE=1` enables the optional actual TheAlgorithms/Python import→Analyze browser smoke test. An actual public API smoke resolved commit `30507bbe41397065728167fb09aa820f9fce8dc7` and inspected `financial/price_plus_tax.py`; this is connectivity evidence, not a model benchmark or cached demo verdict.

All changes for this request are local; no commits or pushes were made for this request. Model/data artifacts, Docker restrictions and repair validation gates are unchanged.

Three focused browser tests passed, including a real public GitHub import→Analyze smoke. The existing no-oracle/domain/No/Yes revision flow and witness/retrieval/twin/ledger/Shield flows passed with the new collapsed-detail interactions. Desktop (1440px) and mobile (390px) screenshots of an actual confirmed-average report were inspected.
